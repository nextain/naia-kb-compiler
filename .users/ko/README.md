# naia-kb-compiler (사람용 한국어 안내)

> 이 디렉터리는 `.agents/`(AI SoT)의 사람용 한국어 미러입니다. 정식 SoT = 루트 `AGENTS.md` + `.agents/context/`.

## 무엇
비전문가가 **자료(URL·문서)를 넣으면** → 자동으로 **구조화 지식베이스**를 만들고 → **운영자가 답한 몇 개 질문을 합격 기준**으로 자가검증해 → **갭만 사람이 확인** → **인용·만료관리·기권**이 붙은 **서빙용 지식**으로 만들어 주는 엔진.

## 핵심 약속
- **전문성은 엔진이** — 운영자는 폼·승인만.
- **종속 없음** — 넥스테인 소유, 누구도 이 엔진/백엔드에 묶이지 않게 **설계로 보장**(언제든 교체). 기업·파트너 권리는 별도 계약. → [`../../OWNERSHIP.md`](../../OWNERSHIP.md)
- **그래프 데이터는 항상, 검색 백엔드는 어댑터** — 벡터든 그래프든 갈아끼움.
