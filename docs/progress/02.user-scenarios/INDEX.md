## MVP 임계 체인 (B 슬라이스)
**UC-001 → UC-002 → UC-003 → UC-009.** (투입 → 구조화 → 정답앵커 검증 → 소비 응용 배선) — 가장 얇게 도는 가치 슬라이스.
UC-005/006/007(검색·거버넌스 일부)·UC-008(export)은 MVP에서 인터페이스만, 채움은 후속.

## NFR 처리
NFR(비종속·가반성·교체가능·안전)은 UC로 안 내려가는 것은 REQ/NFR→TEST-S 직결. 추적 검사기는 NFR을 UC-면제로 처리.
